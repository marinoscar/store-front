# Image assets

All images in this directory are generated by AI. Don't drop hand-curated photos here without renaming — they'll be overwritten the next time the generation script runs against a matching filename.

**Source of truth for the prompts:** [`../../IMAGE_CREATION.md`](../../IMAGE_CREATION.md)
**Generator script:** [`../../scripts/generate-images.sh`](../../scripts/generate-images.sh)

To regenerate any image, edit the prompt in `IMAGE_CREATION.md` and run:

```bash
cd sites/home-improvement
./scripts/generate-images.sh --only <stem> --force
```

…where `<stem>` is one of `hero`, `og-image`, `interior-paint`, `deck-rebuild`, `flooring`, `deck-before`, `deck-after`, `kitchen-before`, `kitchen-after`, `floor-before`, `floor-after`, `owner`, `foreman`, `painter`.
