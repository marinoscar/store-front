# Image creation — Rivadeneira Home Improvement (raul1)

Every marketing image on the raul1 site is generated by AI from prompts in this file. To regenerate (or update) any image, edit its prompt below and run:

```bash
./scripts/generate-images.sh                   # generate any missing images
./scripts/generate-images.sh --force           # regenerate everything from scratch
./scripts/generate-images.sh --only hero,owner # regenerate just those stems
./scripts/generate-images.sh --quality medium  # cheaper while iterating on prompts
./scripts/generate-images.sh --dry-run         # print final prompts, don't call API
```

The script lives at `sites/home-improvement/scripts/generate-images.sh`. It uses the `claude-image` CLI which calls OpenAI's `gpt-image-1` model. The key for the OpenAI account lives at `~/.config/claude-image/openai.env`.

**Cost at `--quality high`** (the default): ≈ $0.17 per image, $2.40 for the full set of 14. Use `--quality medium` (≈ $0.59 total) for fast prompt iteration before committing to a final high-quality run.

After regenerating, rebuild the site so Astro re-encodes & ships the new images:

```bash
pnpm --filter home-improvement build
./scripts/start-raul1.sh   # to push them live
```

## How prompts are assembled

The script concatenates the **common style preamble** below + the per-image **prompt body** + a final **strict negative tail**. This is what keeps every image in the same visual key: same camera language, same palette, same suburban-Texan setting language, and the same hard "no text / no logos / no close-up faces" rules.

If you only want to tweak one image, **edit just its prompt body** — leave the preamble alone unless you want a sweeping style change across all 14.

---

## Common style preamble

```preamble
Photorealistic editorial architectural photograph in a refined American suburban Texan style. The scene evokes a well-built suburban home in the wooded North Houston area — the aesthetic of The Woodlands, Conroe, Willis, Tomball, and Montgomery — with tall loblolly pines and live oaks visible whenever the outdoors or windows are in view, brick-and-Hardie siding architecture, large well-kept lots, mature suburban landscaping, and a refined Texan sensibility (warm, generous, polished without being flashy). Lighting is natural and unhurried: warm late-afternoon golden hour for exteriors, soft directional daylight from windows for interiors. Color palette across the entire set: warm whites, honey-toned and rich-brown woods, deep navy blues, sage and moss greens, hints of brick red, dark charcoal accents — coherent, restrained, magazine-quality. Camera: full-frame DSLR, 35mm or 50mm lens, shallow but not extreme depth of field, sharp focus on the architectural subject. Composition follows the rule of thirds with generous negative space. Mood: aspirational, trustworthy, polished, never gimmicky or stocky.
```

## Common strict negatives (appended to every prompt)

```negatives
Strict exclusions: no readable text, signs, logos, brand names, license plates, labels, or numbers anywhere in frame. No faces in sharp close-up focus; any people are at mid-distance, three-quarter or back angle, partially obscured by hats, hair, or shadow. No close-up of a hand gripping a tool as the focal point. No oversaturated colors, no HDR halo, no obvious stock-photo posing, no visible AI artifacts (extra fingers, melting symmetry, garbled hardware, distorted electrical outlets, warped window frames).
```

### `hero` → `public/images/hero.jpg`

**Subject:** Above-the-fold hero — a freshly renovated open-concept living room interior that immediately reads "what your home could look like after we're done."
**Specs:** 1536×1024, landscape.

```prompt
Wide-angle interior photograph of a beautifully renovated open-concept living room in a North Houston suburban home, late afternoon. Refinished wide-plank white-oak hardwood floor with rich honey grain. Soft warm-white walls. A comfortable cream linen sectional sofa with a deep navy throw blanket. ## Tweaking & regenerating
```

| You want to | Run |
|---|---|
| Generate any missing images | `./scripts/generate-images.sh` |
| Regenerate everything from scratch | `./scripts/generate-images.sh --force` |
| Regenerate just `hero` and `owner` | `./scripts/generate-images.sh --only hero,owner --force` |
| Cheap pass while iterating on prompts | `./scripts/generate-images.sh --quality medium --force` |
| Preview the final assembled prompts without calling the API | `./scripts/generate-images.sh --dry-run` |

After editing a prompt, **regenerate just that image** rather than redoing the whole set — it's faster and cheaper.
